피드백 반영

■ 마이그레이션
  npm run db:migrate    ← 0006 (users.interests)

■ 고친 버그
  1. 찜하면 씨앗판에서 사라지고 해제도 안 됨
     상단 '인기' 카드로 뽑힌 커넥트를 목록에서 빼고 있었는데,
     자기가 찜하면 곧바로 상단으로 올라가 목록에서 사라졌습니다.
     → 상단 카드를 없애고 목록에 그대로 둡니다. 하트로 바로 해제됩니다.

  2. 폼 검증에 걸리면 적어 둔 내용이 사라짐
     React 19는 폼 액션이 끝나면 제어되지 않는 입력을 자동으로 비웁니다.
     → 개설 폼과 프로필 폼의 모든 입력을 state로 들고 있습니다.

  3. 도전 확인 대기가 씨앗판에 안 보임
     → 목록에 노출합니다. 신청은 상세와 서버 양쪽에서 막습니다.

  4. 본인이 만든 커넥트 수정·탈퇴 불가
     → 상세와 마이페이지에 수정 버튼. 이탈/삭제 기능 신규.
        팀장은 후임을 지정해야 나가고, 혼자면 커넥트가 지워집니다.

  5. 개설한 커넥트가 마이페이지에서 참여 중으로 안 보임
     → '내가 개설한' 섹션을 맨 위로 올리고 '참여 중 · 팀장' 배지 추가.

  6. 동일 트랙 커넥트 2개 이상 개설 가능
     → 트랙당 하나로 제한. 취미 하나 + 도전 하나는 허용.

  7. '정성' 워딩 잔존 → '도전'
  8. 목표 시점 상한 2027-01-15 → 2027-01-31

■ 바뀐 입력 방식
  거주지    자유 입력 → 시·도 선택 (경기도 광주시 / 광주광역시 구분)
  관심 태그 → '관심 있는 것' 자유 입력 (요리·창업처럼 목록에 없는 것도)
             users.interests 에 저장. user_tags 는 쓰지 않습니다.
